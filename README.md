# Muqun

**Your coding agents, conversations and terminals — on iPhone, iPad and Android.**

Muqun connects to the agents running on your own computers through
[Muqun Gateway](https://github.com/osuki-dev/muqun-gateway). Start a conversation,
follow its progress, answer a permission request or send the next instruction
from your phone. Your projects and agents stay on your computer.

No Muqun account, hosted relay, analytics or advertising.

## Agent conversations

- **Start and resume conversations.** Choose a computer, project and available
  agent, create a session or return to an existing conversation.
- **Follow the work.** Read streaming replies, reasoning when provided, tool
  calls, command output and file changes in a native conversation view.
- **Keep the conversation going.** Send follow-ups, stop a running turn, and
  answer the permission requests exposed by your agent.
- **Use the agent's controls.** Select models, reasoning levels and modes when
  the connected agent supports them.
- **Move between tasks.** Keep multiple conversations at hand and inspect
  their status without taking over the terminal you are using on your computer.

Native conversation integrations include **Codex, OpenCode, DeepSeek, T3 Code,
FX, Qoder CLI, Claude Code and Pi**. Availability and controls depend on the integrations
included in your installed Gateway and the capabilities of each agent. Models,
reasoning levels, commands, attachments and usage appear when they are provided.

Claude Code and other command-line agents can also be used in terminal
sessions. A terminal session and a native agent conversation offer
different controls.

## Your terminal, wherever you are

- **A real terminal.** Read the original grid, colours, diffs and TUIs, select
  and copy text, and send keys with the on-screen keyboard controls.
- **Computers and workspaces.** Switch between your computers, workspaces,
  tabs and panes; browse project files and inspect changes.
- **Voice and attachments.** Dictate messages, preview audio and images, and
  use attachments where the connected agent supports them.
- **Make it yours.** Choose a home layout and theme, with light and dark
  appearances and eleven interface languages.
